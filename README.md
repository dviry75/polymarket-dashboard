# Polymarket Robot Dashboard

אב־טיפוס Frontend אינטראקטיבי למסך השליטה המרכזי של מערכת מסחר אוטומטית ב־Polymarket.

## מה כלול

- ממשק מלא בעברית ובכיוון RTL
- מצב מכונה, חיבור, זמן שרת והתראות
- יתרת ארנק, אירוע נוכחי, עסקה פתוחה והאירוע הבא
- גרף יתרת ארנק וגרף פעילות מסחר
- פעולות שליטה עם חלוניות אישור ו־Toast
- יומן פעילות ובריאות מערכת
- תצוגה Responsive למחשב, טאבלט ומובייל

## Frontend בלבד

כל הנתונים מגיעים מתוך `app/mock-data.ts`. אין Backend, מסד נתונים, Authentication, חיבור ל־Polymarket, WebSocket או פעולות מסחר אמיתיות.

## הרצה מקומית

```bash
npm install
npm run dev
```

פתח בדפדפן: `http://localhost:3000`
